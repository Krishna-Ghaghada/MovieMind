About MovieMind

MovieMind is a content-based movie recommendation system designed to help you discover movies similar to the ones you already enjoy.

🎬

Movie Recommendations

MovieMind analyzes movie information such as genres, keywords, cast, crew, and overview to find movies with similar content.

🔍

TF-IDF Similarity

TF-IDF is used to represent movie content as numerical vectors, and cosine similarity is used to identify movies with similar content.

💭

Sentiment Analysis

MovieMind also analyzes a user's movie review and predicts whether the sentiment expressed in the review is positive or negative.

How It Works

Select a movie, explore its details, and receive recommendations for similar movies. You can also write a movie review and analyze its sentiment using the sentiment analysis model.
